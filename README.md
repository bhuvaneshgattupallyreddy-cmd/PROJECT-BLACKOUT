# 🕵️ Operation: Blackout

**A Python-based terminal investigation game.**

Welcome to Operation: Blackout, a fictional digital investigation where you take on the role of an investigator and uncover classified information about Project Nightfall.

## 🎮 About the Game

Operation: Blackout is a text-based game made using Python.

Explore the investigation, examine intelligence reports, and investigate different suspects to uncover the mystery.

## ✨ Features

- 🕵️ Enter your own investigator codename
- 🔐 Password-based mission access
- 📁 Classified intelligence reports
- 👥 Investigate three suspects
- 💻 Interactive terminal gameplay
- 🎬 Mission ending sequence
- 🐍 Built entirely with Python

## 🕹️ How to Play

### 1. Download the Game

1. Open this GitHub repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.

### 2. Install Python

Download Python from:

https://www.python.org/downloads/

Make sure Python is installed on your computer.

### 3. Run the Game

Open the extracted game folder.

Open a terminal inside the folder and run:

```bash
python blackout.py
```

The game will start in your terminal.

## 🔑 Mission Access

The game includes a password-based mission access system.

**Mission password:**

`BLACKOUT`

Enter the password when prompted to access the investigation.

## 👥 Investigation

Investigate three suspects:

- **Alex** — Security Officer
- **Morgan** — System Administrator
- **Jordan** — Research Analyst

Review their statements and examine the classified intelligence report.
